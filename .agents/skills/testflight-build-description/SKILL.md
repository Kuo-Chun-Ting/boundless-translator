- 第一段原樣使用 [basic-features.md](assets/basic-features.md)。
- 找出本次建置版本及上一次實際提供外部測試的版本，確認兩者對應的原始碼修訂。不要把相鄰的上傳版本或 commit 當成發布版本；無法確認對應關係時，先詢問。
- 比較兩次修訂，在 `Changes in Build N` 下只寫使用者看得見的變更及測試時應觀察的結果。保持簡短，不重複基本功能或內部實作細節。
- 描述用英文撰寫；不要重複 App Store Connect 的欄位名稱 `What to Test`，也不要加開場白。
