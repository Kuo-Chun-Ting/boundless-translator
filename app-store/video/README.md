# 預覽影片

正式採用 [preview.mp4](preview.mp4)：29.9 秒，截圖翻譯字卡使用「咻」（shoo）音效，片尾使用底部單行音樂署名。

規格：1920 × 1080、30 fps、H.264 High Level 4.0、約 11 Mbps、AAC 256 kbps 48 kHz。

新版先另存供 review；使用者明確要求取代後，才更新 `preview.mp4`。提交依使用者指示，只有已提交版本能從 Git 找回。

音量峰值（混音前）：⌘／數字鍵約 −9.5 dBFS、⇧ 約 −10.1 dBFS、點書本 −12 dBFS、截圖快門 −14 dBFS、四次「咻」聲 −15 dBFS。配樂維持原設定。原始碼與正式影片一致。
