# 粵語（繁體）

## 圖書館入面嘅一個朝早

星期六朝早，阿晴買完早餐，就拎住兩本睇完嘅小說去圖書館。街市嗰邊仲係好嘈，魚檔老闆忙住招呼客人，巴士站亦排咗一條長龍。不過，一行入圖書館，周圍即刻靜咗落嚟。佢喺門口收好把遮，將電話轉做靜音，再去還書機前面排隊。前面嗰位婆婆唔識用部機，阿晴就指住畫面，同佢講應該撳邊個掣。婆婆望住張收據，笑住話：「搞掂喇，唔該晒你呀。」

阿晴本來諗住還完書就走，點知經過新書架，見到一本講香港舊街道嘅書。封面嗰間茶餐廳，佢細個跟阿爸去過幾次，仲記得門口有個紅色汽水箱。佢揭咗幾頁，發現入面有好多未見過嘅相，於是搵咗個靠窗嘅位坐低。窗外有棵大樹，幾隻麻雀喺樹枝之間跳嚟跳去。張枱上面有少少陽光，啱啱照到本書嘅一角，佢將書移近少少，慢慢睇啲相下面寫咗乜。

坐喺對面嘅伯伯見佢睇得入神，細聲問佢係咪住附近。阿晴點點頭，伯伯就指住其中一張相，話以前嗰度係一間戲院，落雨嗰陣，排隊買飛嘅人會迫晒入簷篷底。阿晴一直以為嗰個位置本來就係商場，聽完先知自己記錯咗。佢想記低戲院個名，搵咗一陣都搵唔到支筆。伯伯見到，便喺外套袋拎咗支鉛芯筆出嚟，話：「用住先啦，我仲有一支。」

十點半，兒童區開始講故事。有個着黃色衫嘅細路拖住媽媽隻手，行到一半又折返，話要攞埋自己揀嗰本恐龍書。職員請大家坐喺地氈上，仲提醒小朋友唔好擋住條通道。阿晴聽到隔籬傳嚟一陣笑聲，抬頭望咗望，見到職員正扮緊一隻打乞嚏嘅大象。細路哋笑完，又一齊靜落嚟，等佢揭下一頁。嗰個攞住恐龍書嘅小朋友，終於肯將本書放低，專心聽故事。

阿晴睇完半本書，先記得下星期要幫屋企整幾盆香草。佢去查詢機搵園藝書，打咗「露台種植」，畫面顯示有兩本可以借。書架上嘅編號排得好密，佢來回行咗兩次都搵唔到，最後問職員幫手。原來其中一本放咗喺展覽架，另一本就畀人擺錯咗格。職員搵返本書之後，指住目錄話呢度有講點樣處理積水，應該啱佢用。佢一揭開，就見到自己盆薄荷出過嘅問題。

臨近中午，阿晴將兩本書拎去借書機。部機讀到舊街道嗰本，卻一直讀唔到園藝書。佢冇急住再撳，先將兩本書分開放，試多一次就成功咗。借書期限顯示到下個月，佢即刻喺電話記低日期。轉身嗰陣，佢發現伯伯支筆仲喺自己手上，趕緊行返窗邊還畀佢。伯伯正睇緊報紙，接過支筆，問佢有冇借到想睇嘅書。佢舉起手上兩本書，細聲答：「有呀，仲搵到點救返盆薄荷。」

行出圖書館，外面已經停咗雨，地下仲有幾灘水。阿晴打電話畀阿爸，問佢記唔記得嗰間戲院。阿爸一聽個名，就講起以前同朋友睇夜場嘅事，連散場後去邊度食魚蛋粉都記得。阿晴一路聽，一路行去巴士站，原本只係想還兩本書，結果又借咗兩本返屋企。等車嗰陣，佢低頭望住袋入面本舊街道書，諗住食完晏就攞畀阿爸睇，睇吓佢仲認得幾多個地方。
