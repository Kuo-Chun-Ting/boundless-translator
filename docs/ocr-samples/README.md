# OCR 語言範例

每個 API 語言選項各有一份 Markdown 原文與單頁 PDF。開啟 PDF 後即可截圖測試；要比較辨識速度，請固定顯示比例與截圖範圍。

清單依 2026-10-17 這台 Mac（macOS 27.0.1）的 `VNRecognizeTextRequest.supportedRecognitionLanguages()` 回傳結果，共 33 個語言選項。查詢設定與 App 相同：accurate、自動判斷語言、語言校正。這是 API 支援清單，不代表每篇文章都已通過 OCR 正確率測試，也不代表已涵蓋所有內部模型。

`no-NO`、`nb-NO` 都採 Bokmål 書寫，仍分開提供範例以對應 API 選項；`nn-NO` 採 Nynorsk。`yue-Hans`、`yue-Hant` 分別使用簡體、繁體粵語。`ars-SA` 使用納吉迪阿拉伯語。`vi-VT` 保留 API 實際回傳的代碼。
