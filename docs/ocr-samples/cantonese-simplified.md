# 粤语（简体）

## 图书馆入面嘅一个朝早

星期六朝早，阿晴买完早餐，就拎住两本睇完嘅小说去图书馆。街市嗰边仲系好嘈，鱼档老板忙住招呼客人，巴士站亦排咗一条长龙。不过，一行入图书馆，周围即刻静咗落嚟。佢喺门口收好把遮，将电话转做静音，再去还书机前面排队。前面嗰位婆婆唔识用部机，阿晴就指住画面，同佢讲应该揿边个掣。婆婆望住张收据，笑住话：「搞掂喇，唔该晒你呀。」

阿晴本来谂住还完书就走，点知经过新书架，见到一本讲香港旧街道嘅书。封面嗰间茶餐厅，佢细个跟阿爸去过几次，仲记得门口有个红色汽水箱。佢揭咗几页，发现入面有好多未见过嘅相，于是搵咗个靠窗嘅位坐低。窗外有棵大树，几只麻雀喺树枝之间跳嚟跳去。张台上面有少少阳光，啱啱照到本书嘅一角，佢将书移近少少，慢慢睇啲相下面写咗乜。

坐喺对面嘅伯伯见佢睇得入神，细声问佢系咪住附近。阿晴点点头，伯伯就指住其中一张相，话以前嗰度系一间戏院，落雨嗰阵，排队买飞嘅人会迫晒入檐篷底。阿晴一直以为嗰个位置本来就系商场，听完先知自己记错咗。佢想记低戏院个名，搵咗一阵都搵唔到支笔。伯伯见到，便喺外套袋拎咗支铅芯笔出嚟，话：「用住先啦，我仲有一支。」

十点半，儿童区开始讲故事。有个着黄色衫嘅细路拖住妈妈只手，行到一半又折返，话要攞埋自己拣嗰本恐龙书。职员请大家坐喺地毡上，仲提醒小朋友唔好挡住条通道。阿晴听到隔篱传嚟一阵笑声，抬头望咗望，见到职员正扮紧一只打乞嚏嘅大象。细路哋笑完，又一齐静落嚟，等佢揭下一页。嗰个攞住恐龙书嘅小朋友，终于肯将本书放低，专心听故事。

阿晴睇完半本书，先记得下星期要帮屋企整几盆香草。佢去查询机搵园艺书，打咗「露台种植」，画面显示有两本可以借。书架上嘅编号排得好密，佢来回行咗两次都搵唔到，最后问职员帮手。原来其中一本放咗喺展览架，另一本就畀人摆错咗格。职员搵返本书之后，指住目录话呢度有讲点样处理积水，应该啱佢用。佢一揭开，就见到自己盆薄荷出过嘅问题。

临近中午，阿晴将两本书拎去借书机。部机读到旧街道嗰本，却一直读唔到园艺书。佢冇急住再揿，先将两本书分开放，试多一次就成功咗。借书期限显示到下个月，佢即刻喺电话记低日期。转身嗰阵，佢发现伯伯支笔仲喺自己手上，赶紧行返窗边还畀佢。伯伯正睇紧报纸，接过支笔，问佢有冇借到想睇嘅书。佢举起手上两本书，细声答：「有呀，仲搵到点救返盆薄荷。」

行出图书馆，外面已经停咗雨，地下仲有几滩水。阿晴打电话畀阿爸，问佢记唔记得嗰间戏院。阿爸一听个名，就讲起以前同朋友睇夜场嘅事，连散场后去边度食鱼蛋粉都记得。阿晴一路听，一路行去巴士站，原本只系想还两本书，结果又借咗两本返屋企。等车嗰阵，佢低头望住袋入面本旧街道书，谂住食完晏就攞畀阿爸睇，睇吓佢仲认得几多个地方。
