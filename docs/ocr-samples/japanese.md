# 日本語

## 図書館で過ごす朝

町の図書館は、小さな公園と朝市の間にある。木陰の道を少し歩くと、入口のガラス戸が見えてくる。開館したばかりの時間には、窓際の長い机に日が差している。仕事へ行く前に本を返す人もいれば、ノートを持って静かに読書を始める人もいる。本を借りる予定がなくても、空いている椅子に座ってひと息つくことができる。

入口の近くには、この町の暮らしを紹介する本が並んでいる。川沿いの古い写真を集めた本や、駅前の店について書かれた記録もある。引退したパン職人が一枚の写真を見て、子どもの頃に住んでいた角を見つけた。写真の外側には靴の修理屋があり、雨が降りそうになると店主が椅子を中へ運んでいたという。彼はその思い出を紙に書き、資料を整理している職員に渡した。

奥の小さな部屋では、週末になると近所の人たちが知識や技術を教え合う。今週は取れかけたボタンの縫い方、来週はベランダで育てられる香草の話だ。参加する前に特別な経験を積む必要はない。机を囲んで手元を見せ合い、分からないところがあればその場で質問する。うまく糸を通せない人のために、隣の人が明かりの向きを少し変えていた。

窓際では、外国語を勉強している学生が短い記事を読んでいる。大まかな内容は分かるが、ある表現の意味がつかめず、何度も同じ行に目を戻した。前後の文を読んでから意味を調べ、もう一度段落全体を読むと、話のつながりが見えてきた。彼女は説明を長く写す代わりに、元の文と、自分の生活に置き換えた例文をノートに残した。

同じ机の反対側では、父親と子どもが鳥の図鑑を開いている。公園で見かけた鳥の名前を知りたいらしい。羽の色だけでなく、くちばしの形や尾の長さも比べている。それでもはっきりしなかったので、次は小さなノートを持って観察しようと決めた。急いで答えを選ぶより、分からなかった点を覚えておき、また確かめることにしたのだ。

昼が近づくにつれて、返却用の台車には本が増えていく。職員は本を棚に戻しながら、バスの乗り場や来月の催しについての質問にも答えている。大きな文字の本を探している人も、近所の地図を必要としている人もいる。初めて訪れた人にとって、こうした小さな案内があるだけで、声をかけやすくなる。すべての使い方を先に知っている必要はない。

帰る前に、パン職人はもう一度古い写真を眺めた。町の景色は変わったが、人が集まって話し、助け合う場所は今も必要だと感じたという。学生はノートを閉じ、子どもは選んだ図鑑を抱えた。読み終えた人たちは椅子を机の下へ戻していく。この朝に持ち帰ったものは、答えだったり、思い出だったり、新しい疑問だったりする。静かな時間そのものが、一番役立った人もいるだろう。
